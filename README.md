# Documan

> A document management and productivity platform built around documents, context, organization, traceability, and collaboration.

Documan is a full-stack application designed to go beyond traditional file storage by connecting documents with the context and workflows that make them useful.

It provides a foundation for managing documents, organizing them, controlling access, tracking activity, and building richer productivity workflows around them.

## Product Vision

Documents rarely exist in isolation.

A document usually has:

- an owner
- a purpose
- related information
- organizational context
- access permissions
- a history of changes
- collaborators
- actions that happen around it

Documan aims to bring these elements together into a single product experience.
